# Open in London

A mobile-first, static guide to exhibitions open in London over the next
fortnight. The first local slice uses a horizontal fourteen-day calendar:
each exhibition runs across its open dates and opens a full detail view. It
also includes area and institution filters, a free-entry filter, venue source
links, hover previews, and shareable filter URLs.

## Run locally

```sh
npm install
npm run dev
```

Then open `http://localhost:4321`.

## Checks

```sh
npm test
npm run check
npm run build
```

## Automatic weekly refresh

GitHub Actions refreshes the catalog every Monday at `03:17 UTC`
(`03:17` London time during GMT and `04:17` during BST). It runs the
respectful non-interactive crawler, rejects a run if successful scrapes fall
below 70% of the previous baseline or the catalog is empty, then validates and
builds the site. Only a passing run with generated changes commits `data/` and
`src/data/` to `main`; the resulting Git push is expected to trigger the
existing Vercel deployment.

No weekly manual input is needed. Failed runs use normal GitHub Actions
notifications and retain the summary and coverage diagnostics for seven days.
GitHub-hosted runners can be blocked by some venue sites; a broad drop will
trigger the guard instead of publishing degraded data. `workflow_dispatch` is
available only for optional diagnostics.

## Data

- `src/data/venues.ts` contains venues with verified London exhibitions.
- `src/data/exhibitions.ts` contains venue-sourced records generated by the
  weekly crawler.
- `src/lib/catalog.ts` validates required fields and rejects broken records
  during the build.

The server-rendered calendar uses the latest generated catalog window as a
usable no-JavaScript fallback. Once JavaScript runs, the browser's
`Europe/London` calendar date is authoritative, including across London
midnight and regardless of the visitor's timezone.
